Linglass-Pro 安装向导

Linglass-Pro 在 Linglass（YouTube 日语双语字幕扩展）基础上增加 桌面字幕浮窗与侧栏学习面板：浮窗将字幕保留在桌面上，切换到其他应用后仍然可见； 学习面板显示完整字幕，支持逐句跳转与对照文本导出。

先运行安装脚本：解压后运行 install-macos.command 或 install-windows.bat。macOS 首次运行需右键选择「打开」。 等待脚本结束后，再执行下面 4 个步骤。脚本会从 Chrome 商店获取 Linglass 当前版本并生成 dist 目录。
以下 4 个步骤需要在浏览器中手动完成。
安装后需要登录，才会显示字幕。
  • 字幕由 Linglass 的翻译服务提供。未登录时没有字幕数据， 桌面浮窗与侧栏面板为空。
  • 登录页提供 Google / Apple 登录与邮箱注册。 如果网络无法访问 Google，可直接使用邮箱注册，功能完全一致。

  1. 打开浏览器的扩展管理页

    安装脚本会自动打开该页面。如果没有打开，在地址栏输入 chrome://extensions 并回车；Arc 浏览器使用 arc://extensions。

  2. 打开右上角的「开发者模式」开关

    启用后开关显示为蓝色。该选项只显示页面上的两个操作按钮，不会降低浏览器安全性， 也不影响已安装的其他扩展。

  3. 点「加载已解压的扩展程序」，选中 dist 文件夹

    选中解压目录中的 dist 子目录，其同级目录为 src、tools 与 docs。

    常见失败是选错目录。判断依据是所选目录中能直接看到 manifest.json。未显示扩展名时，类型为 JSON 的文件即为该文件。

  4. 确认安装结果

    扩展列表中出现 Linglass-Pro 卡片即表示安装完成。 打开任意带字幕的日语视频，画面中会出现桌面字幕浮窗，右侧会出现学习面板。

双击安装文件没反应？

macOS：提示「无法打开，因为它来自身份不明的开发者」

这是 macOS 的安全拦截，文件本身没有损坏。处理方式：右键点击安装文件 → 打开 → 在弹窗中再次点击「打开」。 该操作只需执行一次，之后可正常双击运行。

macOS：双击后没有反应

通常是解压过程中丢失了可执行权限。打开「终端」，执行以下命令，并先将文件夹拖入终端以补全路径：

cd 解压目录路径
chmod +x install-macos.command && ./install-macos.command

提示需要安装 Node.js

安装脚本需要 Node.js 来获取 Linglass 当前版本并生成扩展文件，扩展运行时不依赖 Node.js。 从 nodejs.org 下载 LTS 版本， 使用默认选项完成安装，然后重新运行安装文件。

Windows：提示「Windows 已保护你的电脑」

选择「更多信息」→「仍要运行」。原因是安装脚本未进行代码签名。

安装窗口中出现大量滚动日志，是否正常？

正常。窗口中显示的是下载与构建日志，其中的黄色 ⚠️ 警告通常不影响结果。 最后出现「还差 4 步」表示成功；出现 ✖ 表示失败，窗口中会说明原因，可重新运行安装文件重试。

Linglass 发布了新版本，需要如何处理？

Linglass 发布新版本后不会自动同步到本扩展，需要重新执行一次安装： 运行安装文件，获取最新版本并重新生成 dist。 完成后回到扩展管理页，点击 Linglass-Pro 卡片上的「刷新」按钮（↻）。

如何卸载？会留下残留文件吗？

在扩展管理页点击 Linglass-Pro 卡片上的「移除」，然后删除解压目录。 扩展不会在系统中安装其他文件。

它和原版 Linglass 有什么关系？

需要先装原版 Linglass 吗？

不需要。安装脚本会获取 Linglass 当前版本，并与本扩展的源码一起构建成 dist，安装后的扩展包含 Linglass 的全部功能。 如果已经装了商店版本的 Linglass，建议先在扩展管理页将它「移除」，避免两个扩展同时修改字幕。

装好后如果字幕不显示或者浮窗没出来：先确认视频本身有字幕（点视频右下角的 CC 按钮）， 再刷新一次页面。仍然不行的话，把「扩展管理页 → Linglass-Pro → 详情 → 错误」里的信息提交到 GitHub Issues。
