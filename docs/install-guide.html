Linglass-Pro 安装向导

这是 Linglass（YouTube 日语双语字幕扩展）的一个增强版：额外提供 桌面字幕浮窗（字幕留在桌面上，切到别的软件也能看）与侧栏学习面板（整条字幕、逐句跳转、导出对照文本）。

先确认手上是哪个包：
  • 解压后看到 install-macos.command 或 install-windows.bat —— 这是安装器版：先双击它（macOS 第一次要右键 → 打开）， 等它跑完，再做下面 4 步。
  • 解压后直接看到 manifest.json 和一个叫 mod 的文件夹 —— 这是完整包：什么都不用装、不用联网，直接做下面 4 步。
剩下这 4 下点击必须由你亲自点，浏览器不允许任何程序代劳。
装好后要登录一次，才看得到字幕。
  • 这个扩展靠 Linglass 官方的翻译服务出字幕，没登录就没有字幕， 桌面浮窗和侧栏面板都会是空的。
  • 登录页上会看到 Google / Apple 登录和邮箱注册两种方式。 如果你的网络打不开 Google，别在那里反复重试， 直接用邮箱注册一个自己的账号就行 —— 扩展本身和功能完全一样。

  1. 打开浏览器的扩展管理页

    安装程序应该已经帮你打开了。如果没打开，就在地址栏里输入 chrome://extensions 回车（Arc 浏览器用 arc://extensions）。

  2. 打开右上角的「开发者模式」开关

    开关会变成蓝色。这一步只是打开页面上的两个按钮，不会降低安全性， 也不会影响你原来装的其它扩展。

  3. 点「加载已解压的扩展程序」，选中 dist 文件夹

    要选哪一层文件夹，看你手上是哪个包：

    • 完整版 —— 选解压出来的那个文件夹本身 （里面能直接看到 manifest.json 和 mod）。
    • 安装器版 —— 选那个文件夹里叫 dist 的子文件夹 （它旁边还有 src、tools、docs）。
    选错文件夹是最常见的失败：判断标准只有一个 —— 你选中的那一层里要能直接看到 manifest.json。 看不见扩展名也没关系，图标是「一张纸带个小齿轮」那个就是。

  4. 看到卡片出现，去 YouTube 试一下

    列表里多出一张写着 Linglass-Pro 的卡片，就装好了。 打开任意一个带字幕的日语视频：画面里会出现桌面字幕浮窗，右侧会出现学习面板。

双击安装文件没反应？（只有安装器版会遇到）

macOS：提示「无法打开，因为它来自身份不明的开发者」

这是系统的安全拦截，不是文件坏了。解决办法：右键点安装文件 → 打开 → 在弹窗里再点一次「打开」。 只需要做一次，之后双击就正常了。

macOS：双击完全没有反应

通常是解压时丢了「可执行」权限。打开「终端」App，把下面两行粘进去（先按提示把文件夹拖进终端就能填上路径）：

cd 解压出来的文件夹路径
chmod +x install-macos.command && ./install-macos.command

提示要先装 Node.js

安装程序需要它来下载官方基线和生成文件（扩展本身不需要）。按提示到 nodejs.org 下载 LTS 版本，一路默认装完， 再双击一次安装文件即可。

完整版不会遇到这个提示 —— 它什么都不用装。

Windows：提示「Windows 已保护你的电脑」

点「更多信息」→「仍要运行」。这是因为安装脚本没有花钱买数字签名。

安装时的窗口里一堆滚动的英文，正常吗？（只有安装器版会弹这个窗口）

正常。那是下载和构建的日志，中间出现几行黄色 ⚠️ 也多半只是提示。 只要最后出现「还差 4 下点击」就算成功；看到 ✖ 才是失败，窗口里会写原因， 再双击一次重试通常就好。

Linglass 官方更新了，我这边怎么办？

官方发新版不会自动同步到你这里，需要手动换一次：

  • 安装器版：重新双击一次安装文件，它会拉最新官方版本、重新生成 dist。
  • 完整版：向给你这个包的人要一份新包，重新解压。

换完之后回到扩展管理页，点 Linglass-Pro 卡片上的「刷新」按钮（↻）即可。

怎么卸载？会留下垃圾吗？

在扩展管理页点 Linglass-Pro 卡片上的「移除」，然后把解压出来的那个文件夹删掉就行， 不会在系统里留任何东西。

它和原版 Linglass 有什么关系？

需要先装原版 Linglass 吗？

不需要，也不建议同时开着 —— 这个安装包已经包含了官方扩展的全部功能，只是额外叠了增强。 如果你原来装过官方版本，可以先在扩展管理页把它「移除」，避免两边同时改字幕。

「安装器版」和「完整版」到底差在哪？

两个包装的是同一件东西（Linglass 官方代码 + 本项目的改造），区别只在「谁去把官方那份取回来」：

  • 安装器版：从 release 下载的就是这一种。安装时由你的电脑自己去 Chrome 商店取官方那份，所以要先装一次 Node.js 并联网。
  • 完整版：包里已经装好了，拿来即用，通常只在私下分享时才有。
装好后如果字幕不显示或者浮窗没出来：先确认视频本身有字幕（点视频右下角的 CC 按钮）， 再刷新一次页面。仍然不行的话，把「扩展管理页 → Linglass-Pro → 详情 → 错误」里的信息发给我们。
